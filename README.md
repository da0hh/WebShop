# 🛍️ Marketplace — Full-Stack E-Commerce Platform

Веб-приложение маркетплейса, разработанное по концепции современных онлайн-платформ электронной коммерции, таких как **Wildberries** и **Ozon**.

Платформа объединяет покупателей и продавцов в единой системе. Пользователи могут просматривать каталог товаров, добавлять позиции в корзину и избранное, оформлять заказы и оставлять отзывы. Продавцы получают отдельный функционал для управления своими товарами и просмотра статистики продаж.

---

## 🚀 Основные возможности

### 👤 Аутентификация и аккаунты

* Регистрация нового пользователя
* Авторизация по логину и паролю
* Выбор типа аккаунта:

  * Покупатель
  * Продавец
* Создание магазина для продавца
* Профиль пользователя
* Изменение имени пользователя
* Удаление аккаунта
* Выход из аккаунта

---

### 📦 Каталог товаров

* Просмотр доступных товаров
* Карточки товаров
* Отображение цены
* Отображение магазина продавца
* Информация о рейтинге и количестве отзывов
* Просмотр подробной информации о товаре
* Обновление списка товаров
* Добавление новых товаров продавцами

---

### 🛒 Корзина

* Добавление товаров в корзину
* Просмотр содержимого корзины
* Выбор отдельных товаров для покупки
* Выбор всех товаров
* Расчёт общей стоимости
* Расчёт стоимости выбранных товаров
* Очистка корзины
* Оформление заказа

---

### 📋 Заказы

* Создание заказа из корзины
* Просмотр истории заказов
* Хранение информации о покупках пользователя

---

### ❤️ Избранное

Пользователь может добавлять товары в список избранного и управлять им.

Доступны операции:

* Добавление товара в избранное
* Удаление товара из избранного
* Просмотр списка избранных товаров

Логика избранного реализована через отдельную сущность, связанную с пользователем и товаром.

---

### ⭐ Рейтинги и отзывы

Для каждого товара доступна подробная информация:

* Средний рейтинг
* Количество отзывов
* Список отзывов пользователей
* Оценка товара от 1 до 5 звёзд
* Добавление собственного отзыва

Пользователь может открыть карточку товара, добавить его в корзину или избранное, а также оставить оценку и текстовый отзыв.

---

### 🏪 Функционал продавца

Продавцы получают дополнительные возможности:

* Создание собственного магазина
* Добавление новых товаров
* Просмотр списка размещённых товаров
* Просмотр статистики продаж
* Анализ общей выручки
* Просмотр количества проданных товаров
* Просмотр среднего заказа
* Просмотр количества размещённых товаров
* Анализ наиболее популярных товаров

Статистика продавца отображается в отдельном разделе и включает ключевые показатели продаж и выручки.

## 🛠️ Технологический стек

### Backend

* **Python**
* **FastAPI** — разработка REST API
* **SQLAlchemy** — ORM
* **SQLAlchemy Async** — асинхронная работа с базой данных
* **Pydantic** — валидация и сериализация данных
* **Passlib** — работа с хешированием паролей
* **Uvicorn** — ASGI-сервер

В зависимостях проекта используются FastAPI, Uvicorn, Pydantic и Passlib.

### Database

* **SQLite**
* **aiosqlite**
* **SQLAlchemy Async**

Для работы с базой используется асинхронный SQLAlchemy Engine и `sqlite+aiosqlite`.

### Frontend

* **HTML5**
* **CSS3**
* **JavaScript**
* Responsive Design

Интерфейс адаптирован под различные размеры экрана и использует responsive CSS-разметку.

## ▶️ Запуск проекта

### 1. Клонирование репозитория

```bash
git clone <repository-url>
cd <project-directory>
```

### 2. Создание виртуального окружения

```bash
python -m venv venv
```

### 3. Активация окружения

#### Windows

```bash
venv\Scripts\activate
```

#### Linux / macOS

```bash
source venv/bin/activate
```

### 4. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 5. Запуск Backend

```bash
uvicorn main:app --reload
```

После запуска API будет доступно по адресу:

```text
http://127.0.0.1:8000
```

Документация API FastAPI:

```text
http://127.0.0.1:8000/docs
```

### 6. Запуск Frontend

Откройте `index.html` через локальный HTTP-сервер или подключите frontend к запущенному API.
